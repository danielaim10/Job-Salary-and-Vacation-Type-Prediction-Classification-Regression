# Data

Raw data files are not included in this repository (course dataset).

The dataset consists of three CSV files:
- `*_train.csv` — training set, includes target columns (`vacation`, `salary`)
- `*_val.csv` — validation set, includes target columns
- `*_test.csv` — test set, targets hidden

Place the CSV files in this folder before running the notebook, or update the file paths at the top of the notebook to point to your local copy.
